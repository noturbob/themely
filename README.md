# themely — website branch

This branch holds everything that isn't needed to run themely, so it never
lands in a clone or download of `main`:

- `site/` — the website at https://noturbob.github.io/themely/, published by
  `.github/workflows/pages.yml` on every push to this branch
- `design/` — the design spec and implementation plan

The demo GIF, the film and its poster are assets of the
[`media` release](https://github.com/noturbob/themely/releases/tag/media).
The app itself lives on [`main`](https://github.com/noturbob/themely).
